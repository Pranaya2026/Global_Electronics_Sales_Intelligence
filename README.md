# Global_Electronics_Sales_Intelligence
Project Overview

Global Electronics Sales Intelligence is an interactive business intelligence project developed using Microsoft Power BI. The project analyzes global electronics sales data to identify sales trends, product performance, geographical distribution, and business insights.

Objectives

Analyze overall sales performance.

Identify top-performing products and categories.

Compare sales across different countries and regions.

Analyze monthly and yearly sales trends.

Evaluate business performance using KPIs.
